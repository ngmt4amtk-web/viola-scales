# ビオラ 2オクターブ音階

全調（長調・和声的短音階・旋律的短音階・自然的短音階）の2オクターブ音階を、ハ音記号の楽譜と指番号（ポジション移動つき）で練習するWebアプリです。

- 1音ずつ測る: お手本の音（既定 ♩=100 で4拍）→ 自分で弾く → マイクで測って「合う／高い／低い」とセント → 次の音のお手本。
- テンポで鳴らす: 設定したテンポで音階を鳴らします（測りません）。

音程の目標は、独奏の旋律の高さ（A から純正5度で数えたピタゴラスの高さ。開放弦は A から純正5度で調弦）です。
運指は「第1ポジションで弦を渡り、A線はフレッシュの 1-2-移動-1-2」という型で作ったもので、フレッシュ・小野アンナの本の運指を写した物ではありません。

音声は端末の中だけで処理し、録音・送信しません。楽譜の字形は Bravura（Bravura-OFL.txt）。

検査: `node test/core.test.mjs` / `node test/score.test.mjs` / `node test/e2e.mjs`
